# Henrique Gonçalves - Portfolio

Portfólio pessoal de Henrique Gonçalves.

## Desenvolvimento

**Instalar dependências**
```bash
npm install
```

**Executar servidor de desenvolvimento**
```bash
npm run dev
```

**Build para produção**
```bash
npm run build
```

## Tecnologias

- [Next.js](https://nextjs.org) - Framework React
- [Once UI](https://once-ui.com) - Sistema de design
- TypeScript
- MDX para conteúdo

Node.js v18.17+ é necessário.

## Créditos

Este projeto foi construído com base no template [Magic Portfolio](https://github.com/once-ui-system/magic-portfolio) criado por [Once UI](https://once-ui.com).
